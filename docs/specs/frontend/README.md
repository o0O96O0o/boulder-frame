# Frontend Specifications

The frontend is a Vite/React/TypeScript browser application. It handles project setup, direct source upload, athlete selection, output settings, job polling, and download. It does not decode or process the complete source video in the browser.

## Documents

- [Workflow](workflow.md): UI state machine, API calls, direct upload, selection geometry, polling, and download behavior.
- [Phase Evaluation Review](phase-evaluation.md): terminal-job visual diagnostics, phase artifacts, review UI, and authorization boundary.
