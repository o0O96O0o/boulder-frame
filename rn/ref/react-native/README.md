# React Native reference

Local snapshot of the official React Native documentation, retrieved 2026-09-07.

- **Version:** 0.87 for guides, components, and APIs; unversioned current architecture docs.
- **Coverage:** all 203 unique pages in the sidebars of the four entry points below, including nested categories.
- **Format:** one Markdown file per page, following the website URL paths. Internal links to saved pages point to local files when their target anchors exist. The 29 unresolved upstream fragment links retain their original website URLs.
- **Examples:** 153 source files recovered from embedded Expo Snack examples and appended to their pages.
- **Online resources:** images, videos, interactive previews, external sites, and pages outside these four sidebars remain online links. This is a text reference, not a fully offline website.
- **Source fidelity:** text, tables, and code come from the website’s Markdown endpoints; embedded examples come from page HTML. Navigation is removed, source heading anchors retained, and links localized. Some upstream tab labels and formatting may be flattened. Fenced code inside the JavaScript-environment table is converted to HTML code cells so the table remains readable.
